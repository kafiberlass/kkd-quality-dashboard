# Контроль качества данных

Frontend-модуль ККД на React, TypeScript и Ant Design 5. Данные и метрики берутся из mock API, адрес сервиса настраивается через `VITE_API_URL`.

## Запуск

Требуется Docker. При первом клонировании загрузите проект вместе с mock API:

```bash
git clone --recurse-submodules <URL-репозитория>
cd <папка-репозитория>
```

Затем выполните из корня проекта:

```bash
docker compose up --build
```

Откройте http://localhost:5173. Mock API и документация доступны на http://localhost:8000 и http://localhost:8000/docs.

Чтобы изменить параметры, скопируйте `.env.example` в `.env` и задайте `VITE_API_URL` или `MOCK_LATENCY_MS`.

## Возможности

- выбор подразделения и прогона, с учётом статуса иерархии;
- показатели и сравнение с прошлым успешным прогоном по значениям `trend` от API;
- счётчики новых, сохраняющихся и исправленных проблем;
- серверные фильтры и пагинация списка проблем;
- карточка проблемы с фактическими и ожидаемыми значениями, рекомендацией и историей;
- обработка первого прогона, ошибки прогона, пустой выборки и загрузки.

Спецификация решения и критерии приёмки — в [specs/requirements.md](specs/requirements.md) и [specs/design.md](specs/design.md).
